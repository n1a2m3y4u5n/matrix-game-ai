# MatrixGame AI

행렬 연산을 소재로 한 보드 게임에서 여러 AI 에이전트가 대결하거나, 직접 플레이하거나, 현재 상황에서 최적의 수를 추천받을 수 있는 정적 웹앱입니다.

- 데모: https://matrix-game-nys.fly.dev

## 소개

각 플레이어는 3x3 행렬을 하나씩 가지고 5라운드에 걸쳐 수정합니다. 라운드 1~2는 공통 벡터 x와의 곱의 합(axSum)으로,
라운드 3~5는 행렬식(det)으로 승자를 정하고, 승자는 패자들의 행렬에 "명령"(특정 성분을 0으로, 행이나 열을 교환 등)을 내립니다.
이 앱은 그 게임을 AI끼리 붙이는 배틀, 사람이 직접 플레이하는 모드, 현재 상황을 입력하면 다음 수를 추천해 주는 코치 모드 세 가지로 보여줍니다.

## 주요 기능

- AI 배틀: Random, GreedyAx, GodAgent-V4, IL, DQN, PG 여섯 종류의 에이전트를 골라 라운드별로 대결
- 직접 대결: 플레이어가 상대 AI를 고르고 직접 수를 결정
- 코치 모드: 현재 라운드, 내 행렬, 공개된 x 벡터를 입력하면 여러 전략(랜덤/그리디/V4/신경망)의 추천 수를 비교
- 라운드 승리 시 명령(성분 0으로 만들기, 행/열 교환, 성분 교환) 추천
- IL/DQN/PG 에이전트는 브라우저에서 직접 순전파하는 작은 다층 신경망(가중치는 소스에 내장)으로 동작

## 기술

바닐라 JavaScript. 빌드 과정 없는 정적 웹앱(HTML 한 파일, 학습된 신경망 가중치 포함)입니다.
